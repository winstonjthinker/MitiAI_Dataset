# Source Register: ZW-SRC-006 — SIRDC LC-MS Analytical Instrument Data

**Source ID**: ZW-SRC-006  
**Source Name**: SIRDC LC-MS Core Laboratory (Agilent 6545 Q-TOF)  
**Source Type**: Institutional High-Resolution Mass Spectrometry  
**Primary Steward**: SIRDC Analytical Chemistry Core  
**Access Tier**: Controlled Analytical Data Feed  

## 1. Analytical Setup & Parameters
This source directory contains raw instrument output feeds, mass-to-charge (*m/z*) feature matrices, retention time logs, and collision energy profiles generated by the Agilent 6545 Q-TOF LC-MS system operating in positive/negative electrospray ionization (ESI) modes.

## 2. Target Compound Annotations
Features track bioactive secondary metabolite markers including gingerols, shogaols, warburganal, polygodial, ugandensidial, and siphonochilone across MSI confidence levels 1–4.
